<threat_model>
T-3-01: A tag on a commit whose CI run is red or missing.
Mitigation: record the run URL and SHA before tagging; the checkpoint blocks otherwise.

T-3-02: Release assets built from different inputs than the tag.
Mitigation: `pins.txt` in the release must match the tag's commit and recorded tool versions.

T-3-03: Release notes claim arm64 was executed.
Mitigation: state arm64 is artifact-verified only.
</threat_model>
