<objective>
Upgrade the naive and private-target checks from status codes to evidence.

Purpose: F-03 showed that a denied private target still gives the client a
`200` header and then an empty body, so a status-only assertion reports
success for a refused connection. A decoy response likewise carries a status
that says nothing about whether a tunnel opened.
Output: byte-count and body assertions that can distinguish a decoy from a
tunnel, and an ACL assertion that requires the log line.
</objective>

<threat_model>
T-5-01: The decoy assertion passes because the decoy and the tunnel target
return the same status.
Mitigation: assert the decoy body marker and the target byte counter, both of
which are unique to one side.

T-5-02: The ACL assertion passes because the client gave up for an unrelated
reason.
Mitigation: require the `403 no allowed IP addresses` log line and a zero
upstream count in the same window; a timeout alone fails the item.
</threat_model>
