<threat_model>
T-4-04: The tunnel "works" because the client silently fell back to a direct
connection, so the proxy leg is never exercised.
Mitigation: the client config has exactly one outbound, no direct/freedom
fallback, and the inner request is made through the SOCKS inbound only; the
run also asserts the layer4 upstream recorded the connection.

T-4-05: The certificate assertion compares the probe against a stale or
hand-copied certificate.
Mitigation: the expected side is fetched live from the destination in the same
run, and the comparison is field-by-field with an explicit failure per field.

T-4-06: The PROXY assertion only checks that 28 bytes arrived.
Mitigation: parse the version/command byte, family byte, address length, and
the address block; assert each separately.
</threat_model>
