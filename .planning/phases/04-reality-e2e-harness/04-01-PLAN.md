<threat_model>
T-4-01: The harness is written against a hand-built config that has drifted
from the delivery file, so a green run proves nothing about what ships.
Mitigation: derive the overlay from `deploy/Caddyfile` by substitution, then
reverse the substitution and diff; any difference aborts before the listener
starts.

T-4-02: A missing key variable is treated as "skip", and a skipped REALITY leg
looks like a passing suite.
Mitigation: every required variable is checked in preflight and its absence is
an immediate non-zero exit with the variable name printed; the suite has no
skip path.

T-4-03: The non-443 fixture repeats F-01, so a naive/REALITY failure is
misdiagnosed as a protocol defect.
Mitigation: the overlay writes `:8443, a.test:8443` and inherits
`protocols h1 h2`; preflight asserts both strings are present in the rendered
file.
</threat_model>
