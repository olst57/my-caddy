<threat_model>
T-6-01: The smoke reuses a warm tunnel, so it measures one connection rather
than thirty.
Mitigation: each request is a separate client invocation or a separate tunnel
open, and the item asserts the number of upstream connections recorded.

T-6-02: A failure is averaged away by a retry.
Mitigation: no retries inside the smoke; a single non-200 or a timeout fails
the item, and the failing request index is printed.
</threat_model>
